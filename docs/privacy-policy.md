## 수집·저장 데이터

<!-- sw:section id=privacy-data source=src,lib,README.md owner=user gate=no_placeholder -->
Cat-Talk이 다루는 데이터는 다음과 같다.

- **수신 채팅**: 앱 실행 중 참여한 Bongo Cat 로비에서 받은 대화. 발신자 식별자(Steam ID 문자열), 표시 이름, 본문, 수신 시각.
- **내가 보낸 메시지**: 앱에서 전송한 문장과 전송 상태.
- **초안**: 로비별로 작성 중이던 입력.
- **설정**: 테마, 사이드바 접힘, 언어, 알림 on/off, 고양이 반응 효과 on/off, 채팅 투명도, 입퇴장 문구 표시, 고양이 투명화, 상자 자동 오픈 on/off.
- **Steam 차단 여부**: 로비 멤버마다 내가 Steam에서 '모든 대화 차단'했는지(Steam 친구 관계값)를 약 1초마다 읽어 그 사람을 숨기는 데만 쓴다. 앱 설정에는 저장하지 않는다(D-033). 다만 게임 패치(세트 3)가 설치돼 있으면, 게임 화면에서도 그 사람의 고양이를 숨기도록 차단한 사람의 Steam ID를 게임 폴더 목록 파일에 쓴다(아래 '저장 위치').

진단 로그에는 기본적으로 채팅 본문·전체 사용자 ID·로비 입장 코드를 넣지 않는다. 별도 분석·추적 목적의 데이터 수집은 없다.

## 저장 위치·보관

<!-- sw:section id=privacy-storage source=- owner=user gate=no_placeholder -->
저장은 **휘발과 영속 두 계층**으로 분리한다.

- **휘발(메모리)**: 채팅·초안·세션·입퇴장 기록은 인메모리 데이터베이스에만 둔다. **앱을 종료하면 사라지며 디스크에 기록하지 않는다.** 검색·사이드바 로비 목록은 "이번 실행 세션" 범위로 한정된다. 앱 미실행 중의 대화나 종료 전 과거 대화를 서버에서 복원하는 기능은 없다.
- **영속(로컬 디스크)**: 설정과 사용자가 직접 지정한 참여자별 값만 저장해 재실행 후에도 유지한다.
  - `%LOCALAPPDATA%\CatTalk-dev\settings.sqlite3`: 앱 설정(테마·언어·알림 등), 참여자 닉네임(사용자가 정한 표시 이름 — 계정별 Steam ID와 이름, D-032), 앱 차단 목록(계정별로 차단한 Steam ID와 차단 시점의 Steam 이름, D-033). 대화 내용은 들어가지 않는다.
  - `%LOCALAPPDATA%\CatTalk-dev\window-state.json`: 창 배치(도크 방향·채팅 높이·작업표시줄 숨김·마지막 모니터의 식별자와 좌표). 대화 내용은 들어가지 않는다.
  - `%LOCALAPPDATA%\CatTalk-dev\auto_chest\`: 상자 자동 오픈을 켤 때 만드는 게임 파일(`Assembly-CSharp.dll`) 원본 백업과 SHA-256, 패치 작업 파일. 대화 내용은 들어가지 않는다.
  - `<게임 폴더>\CatTalkHidden.ids`: 게임 패치(세트 3)가 설치된 경우에만 만든다. 차단한 사람(앱 차단 ∪ 이번 실행에서 확인한 Steam 차단)의 Steam ID 목록이며 이름·대화 내용은 없다. 앱 실행 때와 목록이 바뀔 때 통째로 다시 쓰고, 앱을 꺼도 남는다(게임이 이 목록으로 고양이를 숨긴다, D-033 3단계).

모든 데이터는 사용자 본인 기기에 머문다. 별도 메시지 서버·클라우드 동기화·다른 메신저로의 전달은 없다. 렌더러는 채팅을 디스크에 영속하지 않는다(off-the-record).

**상자 자동 오픈(앱 내 선택 기능)**: 기본값은 꺼짐이다. 사용자가 켜면 앱이 게임의 `Assembly-CSharp.dll`을 디스크에서 수정하고(수정 전 원본은 위 `auto_chest\` 폴더에 백업한다), 게임 폴더에 플래그 파일 `CatTalkAutoChest.on`을 만든다. 끄면 플래그 파일만 지우며, 수정된 DLL은 남지만 자동 오픈은 동작하지 않는다. 게임 업데이트로 패치가 해제될 수 있고, 그때 앱이 재적용 여부를 묻는다. 같은 패치(세트 3)에는 모든 고양이 투명화(플래그 파일 `CatTalkTransparent.on`)와 차단한 사람의 고양이 숨김(목록 파일 `CatTalkHidden.ids`) 훅도 들어 있다.

## 외부 통신

<!-- sw:section id=privacy-network source=- owner=user gate=no_placeholder -->
Cat-Talk이 수행하는 외부 통신은 다음으로 한정된다.

- **Steam 로비 채팅**: 게임의 기존 Steam 로비 채팅 경로를 통해 메시지를 주고받는다. 별도 수신 포트를 열거나 HTTP 서버를 띄우지 않는다.
- **GitHub Release 자동 업데이트 확인**: 새 버전 확인·내려받기. 사용자가 끌 수 있다.

그 외의 외부 전송은 없다. 상자 자동 오픈은 앱에 포함된 선택 기능이지만 로컬 디스크만 수정하며, 앱이 이 기능을 위해 외부로 전송하는 데이터는 없다. 상자를 여는 동작은 게임이 평소와 같은 경로로 처리한다.
