# 설치 안내

Cat-Talk 설치본을 처음 설치하고 쓰는 방법과 업데이트 방법입니다.

## 요구 환경

<!-- sw:section id=install-requirements source=README.md,pubspec.yaml|package.json owner=user gate=no_placeholder -->
- Windows 10/11 64비트(x64)
- Steam(로그인)과 Bongo Cat
- Python·개발 도구·관리자 권한은 필요 없습니다. 설치본은 Python 등 별도 설치 없이 단독 실행되고, 지금 사용자 계정에만 설치됩니다.

## 받을 파일

[최신 릴리스](https://github.com/postcat23/Cat-Talk/releases/latest)의 Assets에서 `Cat-Talk-Setup-<버전>.exe` 하나만 받으면 됩니다.

| 파일 | 용도 |
|---|---|
| `Cat-Talk-Setup-<버전>.exe` | 설치 파일 |
| `latest.yml`, `Cat-Talk-Setup-<버전>.exe.blockmap` | 앱의 자동 업데이트가 쓰는 파일입니다. 받을 필요가 없습니다. |
| `Source code (zip)`, `Source code (tar.gz)` | 소스 코드입니다. GitHub가 릴리스마다 자동으로 붙입니다. |

## 설치

<!-- sw:section id=install-steps source=README.md owner=user gate=min_steps:1 -->
1. Cat Talk이 실행 중이면 먼저 종료합니다. 작업 표시줄의 Cat Talk 아이콘을 오른쪽 클릭해 [창 닫기]를 누릅니다. 작업 표시줄 아이콘을 숨겨 두었다면 트레이 아이콘을 오른쪽 클릭해 [종료]를 누릅니다.
2. `Cat-Talk-Setup-<버전>.exe`를 실행합니다.
3. SmartScreen 'Windows의 PC 보호' 창이 뜨면 [추가 정보] → [실행]을 누릅니다. 서명되지 않은 앱이라서 뜨는 창이며, 게시자가 '알 수 없는 게시자'로 보이는 것도 코드 서명이 없기 때문입니다(개인이 만든 무료 앱).
4. 선택 화면 없이 바로 설치됩니다. 설치 위치는 `%LOCALAPPDATA%\Programs\cat-talk`이고, 시작 메뉴에 'Cat Talk'이 생깁니다. 바탕화면 바로가기는 만들지 않습니다.
5. 설치가 끝나면 Cat Talk이 자동으로 실행됩니다.

보안 프로그램과 관련해 알아 둘 점이 있습니다.
- 백신 프로그램이 일부 파일을 오탐할 수 있습니다. 서명되지 않은 실행 파일이고, 함께 묶은 사이드카, 게임 메모리를 읽는 도구, 게임 파일을 패치하는 선택 기능이 들어 있기 때문입니다.
- Windows 11의 '스마트 앱 컨트롤'이 켜진 PC에서는 서명되지 않은 앱이 실행 전에 차단될 수 있습니다.

## 첫 사용

1. Steam에 로그인하고 Bongo Cat을 실행한 뒤, 게임 안에서 로비에 들어갑니다.
2. Cat Talk을 켭니다. 설치 직후에는 이미 켜져 있고, 다음부터는 시작 메뉴의 'Cat Talk'으로 켭니다.
3. 화면 끝(기본은 오른쪽)에 채팅 창이 붙습니다. 상단 연결 표시가 '연결됨'이면 채팅할 수 있습니다. '로비 없음'이면 게임에서 로비에 들어갔는지 확인합니다.
4. Enter나 입력창 안 오른쪽의 전송 버튼(↑)으로 보내고, Shift+Enter로 줄을 바꿉니다. 보낸 뒤 약 1.3초 동안은 다음 전송을 기다립니다(버튼 테두리에 링이 차오르고, 쓰던 글은 그대로 남습니다). 전송에 실패한 메시지는 왼쪽의 ↻로 다시 보낼 수 있습니다.
5. 메뉴(☰)에서 테마·채팅 위치·높이·투명도·알림 같은 설정, 차단 목록, 앱 업데이트를 봅니다. 화면 언어 설정은 없습니다(한국어).

대화와 업데이트 확인에 관해 알아 둘 점이 있습니다.
- 대화는 앱을 켜 둔 동안 메모리에만 두며, 종료하면 사라집니다.
- 앱은 켤 때, 실행 중 2시간마다, 메뉴(☰)를 열 때(직전 확인 뒤 30초가 지났으면) GitHub Releases에서 새 버전을 확인합니다. 끄는 설정은 없고, 확인이 실패해도(오프라인 등) 채팅은 그대로 동작합니다. 실패하면 메뉴 '앱 업데이트'에 '업데이트 확인 실패'와 [다시 시도]가 보입니다.

## 업데이트

<!-- sw:section id=install-update source=README.md owner=user gate=no_placeholder -->
새 버전이 나오면 Cat Talk이 백그라운드에서 내려받습니다. 내려받는 동안 메뉴(☰) → '앱 업데이트'에 진행률('새 버전 v<버전> 다운로드 중 N%')이 보이고, 준비되면 '새 버전 v<버전> 준비됨' 알림의 [업데이트]와 '앱 업데이트'의 'v<버전> 설치 준비됨' · [재시작하여 설치] 버튼이 나타납니다. 내려받기가 실패하면 '다운로드 실패'와 [다시 시도]가 보입니다. 적용하는 방법은 세 가지입니다.
- [업데이트]나 [재시작하여 설치]를 누르면 조용히 설치하고 다시 실행합니다.
- 누르지 않아도 다음에 Cat Talk을 정상 종료할 때 설치됩니다.
- 직접 하려면 새 `Cat-Talk-Setup-<버전>.exe`를 받아 위 '설치'와 같은 방법으로 설치합니다(덮어쓰기).

업데이트할 때 유지되는 것과 지워지는 것은 다음과 같습니다.
- **유지:** 설정·닉네임·앱 차단 목록·창 위치(`%LOCALAPPDATA%\CatTalk`), 선택 기능이 만든 게임 파일 백업
- **지워짐:** 대화 기록과 입력창에 쓰던 글. 쓰던 글이 있으면 설치 전에 한 번 더 묻습니다.

업데이트를 잠시 막는 경우도 있습니다.
- 메시지를 보내는 중이면 끝날 때까지 기다립니다.
- 선택 기능의 게임 패치 설치·원본 복원이 진행 중이면 끝날 때까지 [업데이트]·[재시작하여 설치]를 막습니다.
